PROJETO

Documentação

Especificação resumida do SlashGestão.

Objetivo

O SlashGestão é um Web App de Gestão inspirado em dashboards modernos, com foco em organização de tarefas, projetos, indicadores e permissões de usuários.

Requisitos atendidos

  • Acessibilidade com HTML semântico, labels, foco visível, navegação por teclado e alto contraste.
  • Login com validação, sessão e níveis de acesso no protótipo.
  • Dashboard com estatísticas, gráfico de progresso, atividade semanal e alertas.
  • CRUD de tarefas e projetos usando armazenamento local do navegador.
  • Menu lateral responsivo e navegação clara.
  • Níveis Administrador, Editor e Visualizador.
  • Layout responsivo para celular, tablet e computador.

Importante sobre segurança

Este projeto é um protótipo front-end. Um login realmente seguro não deve guardar senhas no JavaScript ou localStorage. Para produção, utilize backend, HTTPS, hash de senhas, sessões/tokens seguros, autorização no servidor e banco de dados.

Hospedagem

O projeto pode ser publicado gratuitamente no GitHub Pages, pois utiliza apenas HTML, CSS e JavaScript. Coloque os arquivos no repositório, ative Pages em Settings → Pages e selecione a branch principal.
